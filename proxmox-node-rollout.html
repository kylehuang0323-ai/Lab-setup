按同一顺序复制下一台 PVE 工作站

本页是后续节点的唯一主入口。它把 PVE-003 已验证的安装、NAS、Windows VM、RDP、Radeon 8060S、USB、本地直显和自动启动流程参数化。遇到异常时再进入 GPU 细节指南或远程访问排障页。

不可直接复制的内容：PVE 节点身份、管理 IP、VM ID、VM MAC、Windows 名称、Windows IP、PCI 地址、IOMMU Group 和 VBIOS。即使硬件型号相同，也必须逐台检测和记录。
可以复用的内容：NAS 中的“直通前 Windows VM 基线”可以恢复到其他节点。最终包含 GPU/USB 的节点备份只用于恢复原节点，不能直接作为通用模板。

验收门 1

2. 安装 Proxmox VE

  1. 从 U 盘启动，选择 Install Proxmox VE (Graphical)。
  2. 按 NVMe 型号和容量选择目标盘；安装会清空整盘。
  3. 单盘节点保持默认 ext4 + LVM-thin。
  4. 设置强 root 密码并保存到受控密码库。
  5. 填写唯一 FQDN、固定管理 IP、网关和 DNS。
  6. 安装完成后拔掉 U 盘并重启。

验收门 6

7. 验证 VirtIO、Guest Agent 和 RDP

Windows 内确认：

Get-Service -Name QEMU-GA
Get-NetAdapter

应看到 QEMU-GA 为 Running，网卡为 Red Hat VirtIO Ethernet Adapter。

qm agent "$VM_ID" ping
qm guest cmd "$VM_ID" get-osinfo
qm guest cmd "$VM_ID" network-get-interfaces

验收门 7

8. 识别当前节点的 PCI 与 IOMMU

先正常关闭 Windows：

shutdown /s /t 0

PVE Shell 确认 VM 已停止，再执行只读检测：

qm status "$VM_ID"

lspci -nn | grep -Ei 'VGA|Display|Audio|USB|Ethernet|Network'
lspci -nnk -d "$GPU_ID"
lspci -nnk -d "$AUDIO_ID"

dmesg | grep -Ei 'AMD-Vi|IOMMU|interrupt remapping' | head -100

显示 GPU 和 Audio 的完整分组：

for ID in "$GPU_ID" "$AUDIO_ID"; do
  DEVICE="$(lspci -Dnnd "$ID" | awk 'NR==1 {print $1}')"
  echo "===== $ID / $DEVICE ====="

  if [ -n "$DEVICE" ] && [ -e "/sys/bus/pci/devices/$DEVICE/iommu_group" ]; then
    GROUP="$(basename "$(readlink "/sys/bus/pci/devices/$DEVICE/iommu_group")")"
    echo "IOMMU GROUP: $GROUP"
    for MEMBER in /sys/kernel/iommu_groups/"$GROUP"/devices/*; do
      lspci -nns "$(basename "$MEMBER")"
    done
  else
    echo "NO IOMMU GROUP"
  fi
done

自动记录实际 PCI 地址：

GPU_PCI="$(lspci -Dnnd "$GPU_ID" | awk 'NR==1 {print $1}')"
AUDIO_PCI="$(lspci -Dnnd "$AUDIO_ID" | awk 'NR==1 {print $1}')"
printf 'GPU_PCI=%s\nAUDIO_PCI=%s\n' "$GPU_PCI" "$AUDIO_PCI"
管理网卡不得出现在 GPU 或 Audio 的 IOMMU Group。不要假设后续节点仍然使用 PVE-003 的 c5:00.0 和 c5:00.1。

验收门 8

9. 从当前节点提取 VBIOS

每台机器单独提取。不要把 PVE-003 的 gmk003-vbios-8060s.bin 复制给 PVE-004/005。
ls -lh /sys/firmware/acpi/tables/VFCT
apt update
apt install -y build-essential bsdextrautils curl

从本仓库取得已验证提取器：

curl -fL \
  https://raw.githubusercontent.com/kylehuang0323-ai/Lab-setup/main/scripts/extract-vfct-vbios.c \
  -o /root/vbios.c

gcc /root/vbios.c -O2 -Wall -Wextra -o /root/vbios
cd /root
./vbios
ls -lh /root/vbios_*.bin

安装当前节点的 ROM：

ROM_NAME="${NODE_NAME}-vbios-8060s.bin"
ROM_PATH="/usr/share/kvm/${ROM_NAME}"
HASH_FILE="/root/${NODE_NAME}-vbios-8060s.sha256"

test -s /root/vbios_1002_1586.bin || {
  echo "ERROR: Radeon 8060S VBIOS not found or empty"
  exit 1
}

install -m 0644 /root/vbios_1002_1586.bin "$ROM_PATH"
sha256sum "$ROM_PATH" | tee "$HASH_FILE"
hexdump -C "$ROM_PATH" | head
ls -lh /root/vbios_1002_1586.bin "$ROM_PATH" "$HASH_FILE"

文件头必须出现 55 aa，文件不能是 0 字节。

验收门 9

10. 配置 VFIO

先备份当前配置：

BACKUP_DIR="/root/${NODE_NAME}-backup/pre-vfio"
mkdir -p "$BACKUP_DIR"
cp -a /etc/modprobe.d "$BACKUP_DIR/"
cp -a /etc/modules "$BACKUP_DIR/modules.backup"
cp -a /etc/default/grub "$BACKUP_DIR/grub.backup" 2>/dev/null || true
cp -a /etc/kernel/cmdline "$BACKUP_DIR/kernel-cmdline.backup" 2>/dev/null || true

加载 VFIO 模块：

for MODULE in vfio vfio_iommu_type1 vfio_pci; do
  grep -qxF "$MODULE" /etc/modules || echo "$MODULE" >> /etc/modules
done

绑定 Radeon 8060S 和 GPU Audio：

cat > /etc/modprobe.d/vfio.conf <<'EOF'
options vfio-pci ids=1002:1586,1002:1640 disable_vga=1
softdep amdgpu pre: vfio-pci
softdep radeon pre: vfio-pci
softdep snd_hda_intel pre: vfio-pci
EOF

cat > /etc/modprobe.d/gpu-blacklist.conf <<'EOF'
blacklist amdgpu
blacklist radeon
EOF

update-initramfs -u -k all

不全局屏蔽 snd_hda_intel，避免影响其他 HDA 音频设备。确认 VM 已停止、MIX 可访问 PVE 后重启：

qm status "$VM_ID"
reboot

本机显示器在 PVE 内核阶段变黑可能是正常现象。从 MIX 重新进入 PVE，先恢复变量再验证：

. /root/pve-node-vars.sh

lsmod | grep vfio
lspci -nnk -d "$GPU_ID"
lspci -nnk -d "$AUDIO_ID"

两个设备都必须显示：

Kernel driver in use: vfio-pci

验收门 10

11. 首次给 VM 添加 GPU

本轮保留虚拟显示器和 RDP，不设置 x-vga=1，不设置 vga: none。

先备份 VM 配置：

NODE="$(hostname)"
BACKUP_DIR="/root/${NODE_NAME}-backup/vm${VM_ID}-pre-hostpci"
CONFIG_PATH="/etc/pve/nodes/${NODE}/qemu-server/${VM_ID}.conf"

mkdir -p "$BACKUP_DIR"
qm config "$VM_ID" > "$BACKUP_DIR/${VM_ID}.conf.txt"
cp -a "$CONFIG_PATH" "$BACKUP_DIR/${VM_ID}.conf"
sha256sum -c "$HASH_FILE"

重新载入变量并再次检测 PCI 地址，然后添加硬件：

. /root/pve-node-vars.sh
GPU_PCI="$(lspci -Dnnd "$GPU_ID" | awk 'NR==1 {print $1}')"
AUDIO_PCI="$(lspci -Dnnd "$AUDIO_ID" | awk 'NR==1 {print $1}')"

qm set "$VM_ID" \
  --hostpci0 "${GPU_PCI},pcie=1,romfile=${ROM_NAME}"

qm set "$VM_ID" \
  --hostpci1 "${AUDIO_PCI},pcie=1,rombar=0"

qm config "$VM_ID" | grep -E '^(bios|machine|cpu|vga|hostpci)'

启动一次：

qm start "$VM_ID"
qm status "$VM_ID"

swtpm_setup: Not overwriting existing state file. 不是错误；最终状态为 running 即可。

Windows 管理员 PowerShell 检查：

Get-PnpDevice -Class Display |
  Format-Table Status,FriendlyName,InstanceId -AutoSize

Get-CimInstance Win32_VideoController |
  Select-Object Name,DriverVersion,Status

安装 AMD 官方驱动，确认 Radeon 8060S 为 OK、无 Code 43；同时从 MIX 验证 RDP。

Test-NetConnection WINDOWS_VM_IP -Port 3389

确认后在 Windows 正常关机：

shutdown /s /t 0

验收门 11

12. 切换到物理 HDMI/DP 直显

保存已工作的 GPU 配置：

BACKUP_DIR="/root/${NODE_NAME}-backup/vm${VM_ID}-gpu-working"
mkdir -p "$BACKUP_DIR"
qm config "$VM_ID" > "$BACKUP_DIR/${VM_ID}.conf.txt"
cp -a "$CONFIG_PATH" "$BACKUP_DIR/${VM_ID}.conf"

将 GPU 设置为主显示并关闭虚拟显示器：

qm set "$VM_ID" \
  --hostpci0 "${GPU_PCI},pcie=1,romfile=${ROM_NAME},x-vga=1"

qm set "$VM_ID" --vga none

qm config "$VM_ID" |
  grep -E '^(bios|machine|cpu|vga|hostpci)'

关闭整个宿主机，等待 30 秒后手动开机：

poweroff

PVE Web 恢复后，不启用自动启动，手动启动 VM 一次：

qm status "$VM_ID"
qm start "$VM_ID"
qm status "$VM_ID"

预期物理显示器出现 Windows；此时 noVNC 没有画面属于正常现象。

验收门 13

14. 三轮手动冷启动验收

手动冷启动连续成功三次前，不启用自动启动。不要使用 Windows 的“重新启动”代替冷启动。

每一轮：

  1. Windows 执行 shutdown /s /t 0。
  2. PVE 确认 VM 为 stopped。
  3. PVE 执行 poweroff。
  4. 等待 30 秒，手动打开 GMK。
  5. 等待 PVE Web 恢复，手动启动 VM 一次。
  6. 验证物理显示、USB、RDP、PVE Web 和 Code 43。

验收门 15

16. 保存最终节点配置和备份

保存最终配置文件：

NODE="$(hostname)"
BACKUP_DIR="/root/${NODE_NAME}-backup/final"
CONFIG_PATH="/etc/pve/nodes/${NODE}/qemu-server/${VM_ID}.conf"

mkdir -p "$BACKUP_DIR"
qm config "$VM_ID" > "$BACKUP_DIR/${VM_ID}.conf.txt"

cp -a "$ROM_PATH" "$BACKUP_DIR/"

在 PVE Web 中将最终 VM 备份到 NAS：

VM备份立即备份nas-pve-backupStop + ZSTD
备份类型用途
直通前通用基线恢复到后续节点；不包含 hostpci、USB、vga:none
当前节点最终备份仅恢复本节点；恢复到其他节点后必须删除节点专属硬件配置
VBIOS + 配置文件随节点归档；VBIOS 不应假设已包含在普通 VM 备份中

17. 黑屏或启动失败时回滚

只要 PVE Web/SSH 可用：

qm stop "$VM_ID"
qm set "$VM_ID" --delete hostpci0
qm set "$VM_ID" --delete hostpci1
qm set "$VM_ID" --delete hostpci2 2>/dev/null || true
qm set "$VM_ID" --vga std
qm set "$VM_ID" --onboot 0

mv /etc/modprobe.d/vfio.conf /etc/modprobe.d/vfio.conf.disabled

for FILE in \
  /etc/modprobe.d/gpu-blacklist.conf \
  /etc/modprobe.d/gmk003-gpu-blacklist.conf \
  /etc/modprobe.d/pve-blacklist.conf
do
  [ ! -f "$FILE" ] || mv "$FILE" "$FILE.disabled"
done

update-initramfs -u -k all

恢复对应 Bootloader 的备份后更新 GRUB 或 proxmox-boot-tool，再重启。详细分流见 GPU 指南紧急回滚。

AMD reset bug 常见表现是第一次冷启动正常，VM 重启后黑屏。不要反复执行 stop/start；正常关机，整机断电等待 30 秒后冷启动，并且只启动 VM 一次。
